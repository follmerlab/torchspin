# Test Reference Data Provenance

**Last updated:** 2026-04-17

This document tags each `.mat` reference file with its source (MATLAB EasySpin
or Python torchspin) to guard against circular validation.

## Source Key

| Tag | Meaning |
|-----|---------|
| **MATLAB** | Generated by running MATLAB EasySpin functions. Independent oracle. |
| **MATLAB-gen** | Generated by a MATLAB `.m` script in this directory. Independent oracle. |
| **Python** | Generated by torchspin Python code. NOT an independent oracle — tests using these only verify self-consistency, not correctness against MATLAB. |
| **External** | Real experimental data or data from an external source. |

validate correctness against MATLAB.

## Notes

1. Files tagged "MATLAB" are the authoritative source of truth for numerical
   correctness. Any test that compares torchspin output against these files is
   performing genuine cross-validation.

2. Files tagged "Python" should be treated with caution. If the generating code
   had a bug when the reference was created, the test will pass even though the
   output is wrong. Consider regenerating these in MATLAB for true validation.

3. The cardamom and mdload references are stochastic — exact reproduction is not
   expected. Tests use cosine similarity > 0.7 or qualitative shape matching.
